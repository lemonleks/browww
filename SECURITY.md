# Security policy

Browww is a personal fork maintained on a best-effort basis. Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/lemonleks/browww/security/advisories/new), not in public issues.

If the problem also affects upstream [Boring Notch](https://github.com/TheBoredTeam/boring.notch), please report it to The Bored Team as well. Report vulnerabilities in third-party dependencies to their maintainers.
